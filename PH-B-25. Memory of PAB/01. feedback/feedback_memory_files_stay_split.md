"메모리 파일이 계속 늘어나니 하나로 합쳐서 운영하자"는 안은 **2026-07-26에 이미 검토하고 기각했다.** 다시 제안하지 말 것.

**Why:** 1회성 수동 병합은 가능하지만 유지되지 않는다. 이후 새 메모리를 저장할 때마다 시스템 지침대로 "새 파일 + 목차 한 줄" 방식으로 돌아가기 때문에, 합쳐놓은 상태가 곧 깨진다. 구조적 한계라 운영 규칙으로 덮을 수 없다.

**How to apply:** 파일 개수가 많아 보인다는 지적이 나오면 병합을 권하지 말고, 파일 수는 "요청 횟수"가 아니라 "서로 다른 주제 개수"에 비례한다는 점을 설명할 것. 같은 주제가 다시 나오면 기존 파일을 고치고, 새 주제일 때만 파일을 만든다. 목차(`MEMORY.md`)가 길어지는 게 문제라면 [[cerry-link-symlink-recovery]]와 별개로 목차 자동 생성을 검토하는 쪽이 맞다.
