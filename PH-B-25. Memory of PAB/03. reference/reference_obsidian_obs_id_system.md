## 옵시디언은 노션과 **다른 번호대**를 쓴다

**팹(26맥) 옵시디언 금고 `01. PSW`의 ID는 `OBS-*`다.** 노션의 `ESL-*`을 옵시디언에 옮겨 적지 말 것 — 260804에 페리가 **일부러 갈라놓기로 결정**했다. 양쪽이 각자 번호를 매기면 같은 `ESL-B-20`이 두 곳에서 태어나기 때문이다. 노션은 노션대로, 옵시디언은 옵시디언대로 센다.

시리얼의 뜻은 [[id-and-log-convention]]과 같다 — **A 브랜드 / B 프로젝트 / C 문서.** 다만 자리수를 3으로 고정했다 (`OBS-B-001`). 노션 `ESL-B-19`와 모양이 다른 건 의도된 것으로, 자리수가 섞일 때 이름순이 `B-14, B-15, B-6` 으로 엉키는 문제를 아예 없애려는 것이다. `OBS-*`는 드라이브 폴더명과 묶이지 않아 모양을 바꿔도 부딪히지 않는다.

## ⚠️ 자동 채번은 없다 — 260804에 철거됨

같은 날 만들었던 Templater 자동 채번 템플릿(`00. 템플릿/새 노트.md`)을 **페리가 안 쓰겠다고 해서 지웠다.** Templater 플러그인과 빈 템플릿 폴더까지 함께 제거했고, 지금 볼트에는 **커뮤니티 플러그인이 하나도 없다.**

- 백업: `~/.claude/backups/obsidian-template-260804/` (템플릿·플러그인·플러그인 목록)
- **ID는 이제 사람이 직접 붙인다.** 새 노트에 ID를 넣으려면 기존 `OBS-*` 노트들을 훑어 다음 번호를 손으로 정한다.
- **"채번이 안 된다"는 고장이 아니다.** 템플릿이 사라진 걸 보고 복구하려 들지 말 것 — 의도된 상태다. 되살리려면 페리가 먼저 말해야 한다.
- 되살릴 일이 생기면 **Templater 2.20.6**을 써야 한다. 2.21부터 `minAppVersion`이 1.13.0인데 팹 옵시디언은 1.12.7이라, 최신을 넣으면 목록에는 보이는데 켜지지 않는다 (260804에 실제로 겪음).

## 앱 밖에서 설정 파일을 고치면 즉시 반영되지 않는다

옵시디언이 켜진 채로 `.obsidian/*.json` 을 고치면 **앱은 예전 상태를 계속 들고 있다.** 260804에 `slash-command` 를 파일로 켰는데 `/` 가 안 먹은 원인이 이것이었다. 해결은 **Cmd+R(앱 새로고침)** 또는 설정 화면에서 직접 토글. 파일만 고치고 "켰습니다" 라고 말하지 말 것 — 페리에게 Cmd+R 을 안내해야 한다.

**26맥에는 osascript 클릭 권한(손쉬운 사용)이 없다.** 화면 캡처(`screencapture`)와 앱 전환(`activate`)은 되지만 좌표 클릭은 `-25211` 로 막힌다. 옵시디언은 크롬이 아니라 브라우저 도구로도 못 만진다 — **GUI 조작이 필요하면 페리에게 부탁할 것.** 다만 화면을 찍어서 눈으로 확인하는 것은 가능하니, 상태 확인은 직접 하고 클릭만 부탁하면 된다.
